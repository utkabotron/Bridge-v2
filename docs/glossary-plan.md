# Единый глоссарий имён: план

Решение 2026-10-06. Исходное состояние: у каждого чата свой глоссарий, LLM угадывает огласовку
имени заново в каждом чате — школа גבעולים вышла как Гивъолим / Гевалим / Геваулим / Гвуллим
в 7 чатах 3 пользователей; имена людей тоже расходятся (אורי: Ори/Ури, הגר: Агар/Хагар).
В профилях ~850 уникальных имён: 292 в глоссариях, 345 участников, 215 упомянутых людей.

Решения пользователя: один словарь на сервис (ключ — иврит), чтение проверяется по источнику
(латинское написание с сайта/карт/вики), новые имена одобряются через утренний дайджест,
имена людей тоже в словаре, переопределение для одного чата остаётся; при первичном переносе
совпавшие с источником принимаются автоматически, в кнопки — только спорные.

Отмечать `[x]` по факту выкатки на прод, с датой.

## Шаг 1 — словарь и быстрый поиск (поведение не меняется)

- [ ] Миграция: `glossary` (source + language → translation, kind, status
      candidate/proposed/verified/locked/rejected, evidence, confidence, chat_renderings,
      счётчики) и `glossary_override` (chat_pair_id + source → translation);
      `glossary_global` вливается как `locked`
- [ ] `bridge_shared.glossary_match`: нормализация (никуд, гереш), слова, отрезание приставок
      ו/ה/ב/ל/מ/ש/כ, фразы до 4 слов — «גיל» не находится внутри «רגיל»
- [ ] processor: словарь в памяти, перечитывается при смене сигнатуры (count + max updated_at),
      проверка раз в минуту; в промпт — только найденные verified/locked + override чата
- [ ] `/api/glossary` и `/api/glossary/override` на новой таблице, мгновенная перезагрузка
- [ ] Строитель не предлагает имена со статусом verified/locked
- [ ] Имена людей хранятся по словам («דנה», «דרחי»), связи («ребёнок X») — только в профиле чата

## Шаг 2 — резолвер

- [ ] `flows.glossary_resolver --import`: имена из всех профилей → `candidate`
      с `chat_renderings` ({вариант: в скольких чатах})
- [ ] Резолвер: места/организации — веб-поиск официального латинского написания → русский
      вариант + источник + уверенность; люди — устоявшаяся транслитерация, пачками, без поиска
- [ ] Пробный прогон на 20 спорных именах (`--dry-run`), оценка качества и стоимости

## Шаг 3 — первичный перенос

- [ ] Полный прогон резолвера по ~850 именам
- [ ] Авто-принятие (`verified`): вариант резолвера совпал с единогласным вариантом чатов и
      уверенность ≥ порога; остальное — `proposed`
- [ ] В дайджесте одна строка «принято автоматически: N»

## Шаг 4 — одобрение в дайджесте

- [ ] После дайджеста — сообщение «Новые имена», до 10 в день: `иврит → вариант (источник)`
      и кнопки ✅ / ✏️ / ❌
- [ ] ✏️ — бот просит ответ с правильным вариантом → `locked`; ❌ → `rejected`, больше не
      предлагается
- [ ] Callback только для админов, сообщение после нажатия показывает решение

## Шаг 5 — переключение строителя

- [ ] Строитель профиля не пишет переводы имён — только кандидатов в `glossary`
      (новое имя, встреченное несколько раз); описание, тон, связи людей — как раньше
- [ ] Оценщик: плохие переводы с записью → запись «под вопросом» в дайджест, не удаление;
      `locked` не трогает
- [ ] Резолвер каждую ночь берёт новых кандидатов
