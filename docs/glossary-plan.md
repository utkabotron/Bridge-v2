# Единый глоссарий имён: план

Решение 2026-10-06. Исходное состояние: у каждого чата свой глоссарий, LLM угадывает огласовку
имени заново в каждом чате — школа גבעולים вышла как Гивъолим / Гевалим / Геваулим / Гвуллим
в 7 чатах 3 пользователей; имена людей тоже расходятся (אורי: Ори/Ури, הגר: Агар/Хагар).
В профилях ~850 уникальных имён: 292 в глоссариях, 345 участников, 215 упомянутых людей.

Решения пользователя: один словарь на сервис (ключ — иврит), чтение проверяется по источнику
(латинское написание с сайта/карт/вики), новые имена одобряются через утренний дайджест,
имена людей тоже в словаре, переопределение для одного чата остаётся; при первичном переносе
совпавшие с источником принимаются автоматически, в кнопки — только спорные.

Отмечать `[x]` по факту выкатки на прод, с датой.

## Шаг 1 — словарь и быстрый поиск (поведение не меняется) — выкачено 2026-10-06

- [x] Миграция: `glossary` (source + language → translation, kind, status
      candidate/proposed/verified/locked/rejected, evidence, confidence, chat_renderings,
      счётчики) и `glossary_override` (chat_pair_id + source → translation);
      `glossary_global` вливается как `locked`
- [x] `bridge_shared.glossary_match`: нормализация (никуд, гереш), слова, отрезание приставок
      ו/ה/ב/ל/מ/ש/כ, фразы до 4 слов — «גיל» не находится внутри «רגיל»
- [x] processor: словарь в памяти, перечитывается при смене сигнатуры (count + max updated_at),
      проверка раз в минуту; в промпт — только найденные verified/locked + override чата
- [x] `/api/glossary` и `/api/glossary/override` на новой таблице, мгновенная перезагрузка
- [x] Строитель не предлагает имена со статусом verified/locked
- [x] Имена людей хранятся по словам («דנה», «דרחי»), связи («ребёнок X») — только в профиле чата

## Шаг 2 — резолвер

- [x] `flows.glossary_resolver --import`: имена из всех профилей → `candidate`
      с `chat_renderings` ({вариант: в скольких чатах}) — 2026-10-06: 827 (285 мест/орг, 541 человек)
- [x] Резолвер: места/организации — веб-поиск официального латинского написания → русский
      вариант + источник + уверенность; люди — устоявшаяся транслитерация, пачками, без поиска
- [x] Пробный прогон на 20 спорных именах (`--dry-run`), оценка качества и стоимости —
      2026-10-06: места/орг ≈ $0.008 токенов + веб-поиск на имя, люди ≈ $0.0002 на имя;
      после правки промпта названия транслитерируются (שער הדר → Шаар Хадар, не «Ворота»)

## Шаг 3а — имена, которые ещё и обычные слова (найдено при выкатке шага 3)

Полный прогон 2026-10-06 ($2.68): verified 456 (371 человек, 85 мест/орг), proposed 244,
rejected 126. С verified в промпте живая проверка дала «אני עמוס היום» → «Я сегодня Амос»
и «יש לנו אופק חדש» → «У нас новый Офек (Школьная образовательная платформа…)» — модель
слушается подсказки и копирует пояснение. Откат через 38 мин: `GLOSSARY_USED_STATUSES=locked`
(за это время 2 сообщения, оба без затронутых слов).
